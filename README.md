Student Performance Analytics System

Project Overview

The Student Performance Analytics System is a beginner-friendly Python project that analyzes student marks and attendance using Pandas and NumPy.

Objectives

- Calculate total and average marks.
- Assign grades based on average marks.
- Identify pass and fail results.
- Find the highest and lowest student performance.
- Calculate subject-wise average marks.
- Display the top three performers.
- Check student attendance status.

Technologies Used

- Python
- Pandas
- NumPy
- Google Colab
- GitHub

Dataset

The dataset contains student IDs, names, departments, marks in Python, Sensors and Actuators, and attendance percentages.

Features

1. Total and average marks calculation.
2. Grade assignment using conditional statements.
3. Pass/fail checking for each student.
4. Highest and lowest performance analysis.
5. Subject-wise statistical analysis.
6. Top three student identification.
7. Attendance status classification.

Project Files

- "student_performance.ipynb" — Python code and analysis.
- "student_performance.csv" — Student dataset.

Learning Outcomes

This project helped me understand Python functions, conditional statements, loops, Pandas DataFrames, NumPy calculations, and basic data analysis.

Conclusion

The project demonstrates how Python, Pandas, and NumPy can be used to analyze student performance and summarize academic results.
